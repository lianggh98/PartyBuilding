## 4. P1：基础技术路线比较

只比较并推荐一种优先实施方案：

- **方案 A**：继续改造 PartyBuilding，补强服务端身份认证、权限校验、操作审计等能力。
- **方案 B**：引入成熟 Java 管理框架（参考 RuoYi-Vue-Pro），迁移或复用 PartyBuilding 业务代码和 Vue 页面。

从**代码复用、兼容性、安全、前后端迁移量、后续维护**五个角度给出有证据的判断。

额外检查：
- 是否存在无鉴权接口、前端伪登录、基于请求参数的权限判断、敏感数据明文或泄露风险。
- 原仓库及参考仓库许可是否允许预期使用，是否涉及第三方商业授权。
- 是否适合单体部署；**不引入微服务**，除非有现有业务的必要性证据。
